High-fidelity mobile UI, clean and modern aesthetic, light blue and white color palette. Features a focus on property listings and a user-friendly search experience.  App consists of a top header with the title 'Let's Find your Favorite Home' and a user avatar. Below is a search input field with the placeholder text 'Search by Address, City, or ZIP', and a filter button. A horizontal scrollable segmented control displays options like 'Recomended', 'Top Rates', and 'Best Offers'. Property cards with rounded corners display hero images, titles like 'Lorem House', price '$340/month', and location details. A section titled 'Near You' displays a list of apartment cards with star ratings, titles like 'Woodland Apartment', address, and price. Bottom navigation bar with icons for home, map, favorites, and profile.
